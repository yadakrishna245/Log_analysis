📖 How to Generate Jira API Token (PAT)

Step 3: Click "Create API token"
Step 4: Enter a label (e.g., "LogSherlock")
Step 5: Click "Create"
Step 6: Copy the token (⚠️ you can only see it once!)
Step 7: Paste it in the field above

⚠️ Important:
• Use your email (not username) in the Email field above
• SSO/Okta push won't work — API tokens bypass SSO
• Token never expires unless you revoke it
• Stored only in YOUR browser — never sent to our server
🔒 Privacy: Credentials stored in browser localStorage only. Never sent to our servers. Jira API calls are proxied through the app to avoid CORS — your token is used per-request and not stored server-side.
💡 Tip: Generate a PAT (Personal Access Token) from Jira — it works without SSO/Okta push notification for API calls.

🛠️ Troubleshooting Quick Fixes
# UI not loading (502)
sudo morpheus-ctl restart morpheus-ui

# VM won't start (permission)
sudo chown qemu:qemu /var/lib/libvirt/images/<vm>.qcow2
sudo restorecon -Rv /var/lib/libvirt/images/

# Libvirt down
sudo systemctl start libvirtd

# DB won't start
sudo rm -f /opt/morpheus/embedded/var/mysql/*.pid
sudo morpheus-ctl start mysql
sudo morpheus-ctl db-repair

# RabbitMQ stuck
sudo morpheus-ctl restart rabbitmq

# Elasticsearch red
curl -X DELETE localhost:9200/morpheus-logs-old.*
sudo morpheus-ctl restart elasticsearch

# Full reset
sudo morpheus-ctl stop && sleep 10 && sudo morpheus-ctl start
sudo morpheus-ctl reconfigure
