1. What is LogSherlock Pro?

LogSherlock Pro is a fully offline log analysis tool built for HPE VME L4 Support Engineers. It scans customer log bundles (.tar.gz / .zip) and instantly identifies root causes using 455 known error patterns.

Key Facts:
  • ✅ Runs 100% in your browser — no cloud, no server backend
  • ✅ Customer log files NEVER leave your machine
  • ✅ Works on Windows, Linux (Ubuntu/RHEL), and macOS
  • ✅ Only 4 files needed — total size ~252 KB
  • ✅ No pip install, no npm, no Docker — just Python standard library
  • ✅ Optional AI features via GitHub Copilot (HPE Business license)

4. Install Python

⚠️ Python 3.10+ is the ONLY prerequisite. Most HPE team laptops already have it. Check first: python --version or python3 --version

🪟 Windows Installation

Option A: Download from python.org (Recommended)

1
Go to https://www.python.org/downloads/
2
Click "Download Python 3.11.x"
3
Run the installer → ⚠️ CHECK "Add Python to PATH" at the bottom!
4
Click "Install Now" → Wait → Done

Option B: Using winget (Windows 11)

winget install Python.Python.3.11

Verify:

python --version
# Expected: Python 3.11.x

🐧 Ubuntu / Debian Installation

sudo apt update
sudo apt install python3 -y

# Verify:
python3 --version
# Expected: Python 3.10+ (Ubuntu 22.04 ships with 3.10)

🐧 RHEL / CentOS / Fedora Installation

sudo dnf install python3 -y

# Verify:
python3 --version
# Expected: Python 3.9+ (RHEL 9 ships with 3.9, RHEL 8 use 3.11 from AppStream)

RHEL 8 (if python3 is older than 3.10):

sudo dnf install python3.11 -y
python3.11 --version

🍎 macOS Installation

# Using Homebrew:
brew install python@3.11

# Verify:
python3 --version

5. Setup on Windows

1
Download the ZIP file
Get LogSherlock-Pro.zip from your team lead or download from GitHub repo.
2
Extract the ZIP
Right-click → Extract All → Choose location (e.g., C:\Tools\LogSherlock-Pro-Local)
3
Open PowerShell / CMD / VS Code Terminal
Press Win+X → "Windows Terminal" or open VS Code and press Ctrl+`
4
Navigate to the folder and start the server 
cd "C:\Tools\LogSherlock-Pro-Local"
python server.py
5
Open browser
Go to: http://localhost:8888
✅ You should see the LogSherlock Pro login screen.
6
Enter your name and license key
Get your license key from your admin → Enter it → App unlocks!
🛑 To stop the server: Press Ctrl+C in the terminal.
🔄 To restart: Just run python server.py again.

6. Setup on Linux (Ubuntu / RHEL)

1
Get the ZIP file
Copy LogSherlock-Pro.zip to your home directory via SCP/USB/shared folder.
2
Extract the ZIP 
cd ~
unzip LogSherlock-Pro.zip -d LogSherlock-Pro-Local
3
Start the server 
cd ~/LogSherlock-Pro-Local
python3 server.py
4
Open browser
Go to: http://localhost:8888
If using a headless server, use SSH tunnel:
# From your local machine:
ssh -L 8888:localhost:8888 user@server-ip
# Then open http://localhost:8888 in your local browser
5
Enter name + license key → Start analyzing!
💡 Run in background (optional): 
nohup python3 server.py &
# Server keeps running even if you close the terminal
# To stop: kill $(lsof -t -i:8888)

8. GitHub Copilot AI (Optional)

This is OPTIONAL. LogSherlock Pro works perfectly without AI. AI adds: explanations, Jira reply generation, and investigation guides.

How to Enable (2 clicks)

Click the ⚙️ Settings gear icon in the app sidebar
2
Click "🚀 Sign in with GitHub Copilot"
3
A code appears → Go to github.com/login/device → Enter the code → Authorize

9. Troubleshooting

ProblemSolution
localhost refused to connectserver.py is not running. Open terminal → python server.py
'python' is not recognizedPython not in PATH. Reinstall Python and CHECK "Add to PATH"
Address already in usePort 8888 busy. Kill it: netstat -ano | findstr 8888 (Windows) or lsof -i:8888 (Linux)
Scan shows 0 findingsLog bundle may not contain known patterns. Try a different file.
Large file takes too longNormal for 3GB+ bundles. Wait for progress bar. UI won't freeze.
Copilot sign-in failsMake sure server.py is running (not python -m http.server). Check internet.
License key rejectedKey may be expired. Ask admin for a new key.
python3: command not found (Linux)sudo apt install python3 or sudo dnf install python3

Port Conflict Resolution

Windows:

# Find what's using port 8888:
netstat -ano | findstr 8888
# Kill it (replace PID):
taskkill /PID 12345 /F

Linux:

# Find and kill:
sudo lsof -i:8888
sudo kill -9 $(lsof -t -i:8888)

10. FAQ

Do I need internet?No. Scanning works 100% offline. Internet only needed for optional AI features.
Can multiple people use it?Yes. Each person runs their own copy on their laptop. No shared server.
