# 🔑 LogSherlock Pro — License Key Guide

## Overview

LogSherlock Pro requires a valid license key to activate. Keys are generated by the admin using a PowerShell script and shared with team members.

**License Types:**
| Type | Duration | Use Case |
|------|----------|----------|
| Trial | 7 days | Quick evaluation |
| Standard | 30 days | Monthly team access |
| Extended | 90-365 days | Long-term projects |
| Lifetime | Never expires | Permanent access |

---

## 📥 Step 1: Download the License Generator

The `Generate-License.ps1` file is included in the repository under `LogSherlock-Pro-Local/`.

If you don't have it locally, download it from:
```
https://github.com/yadakrishna245/Log_analysis/blob/main/LogSherlock-Pro-Local/Generate-License.ps1
```

---

## 🔧 Step 2: Open PowerShell

1. Press `Win + X` → Select **Windows Terminal** or **PowerShell**
2. Navigate to the folder containing `Generate-License.ps1`:

```powershell
cd C:\path\to\LogSherlock-Pro-Local
```

---

## 🚀 Step 3: Generate a License Key

### Generate a 7-day trial key (default):
```powershell
.\Generate-License.ps1 -Days 7
```

### Generate a 30-day key:
```powershell
.\Generate-License.ps1 -Days 30
```

### Generate a 90-day key for a specific person:
```powershell
.\Generate-License.ps1 -Days 90 -Name "John Smith"
```

### Generate a 1-year key:
```powershell
.\Generate-License.ps1 -Days 365
```

### Generate a LIFETIME key (never expires):
```powershell
.\Generate-License.ps1 -Lifetime
```

### Generate multiple keys at once (for a team):
```powershell
.\Generate-License.ps1 -Days 30 -Count 5 -Name "HPE L4 Team"
```

## 🔓 Step 5: Activating the License (For End Users)

When a new user opens LogSherlock Pro for the first time:

1. **Enter your name** → Click "Continue"
2. **Enter the license key** → Paste the key you received (e.g., `IEAZ-00FC-0BC1-12RQ`)
3. **Click "Activate License"**
4. ✅ App unlocks and is ready to use!

---

## ⏰ What Happens When License Expires?

| Days Left | What Happens |
|-----------|--------------|
| 3 days | ⚠️ Yellow warning banner appears at top of app |
| 1 day | ⚠️ Warning continues showing |
| 0 days (expired) | 🔒 App locks — shows "License Expired" screen |

**To renew:** Get a new key from the admin and enter it in the renewal screen.

## ❓ Troubleshooting

### "Execution Policy" error when running the script
```powershell
Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope CurrentUser
```
Or run with bypass:
```powershell
powershell -ExecutionPolicy Bypass -File .\Generate-License.ps1 -Days 30
```

### "Invalid license key" error in the app
- Make sure you're entering the key exactly as generated (with dashes)
- Key format must be: `XXXX-XXXX-XXXX-XXXX`
- Keys are case-insensitive (auto-uppercased)

### Lost your license key?
- The admin can generate a new one anytime
- Old keys continue to work until they expire
- Multiple keys can be active simultaneously

### Want to reset everything (for testing)?
Open browser console (F12 → Console) and run:
```javascript
localStorage.clear();
location.reload();
```

---

## 🔐 Security Notes

- License keys are validated **client-side** (no server needed)
- Keys encode the expiry duration using checksum verification
- Keys are stored in browser `localStorage` (per-machine, per-browser)
- No internet connection required for validation
- Each user's license is independent (per-browser isolation)
